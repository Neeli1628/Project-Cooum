# Robots

Built by academy teams. Each robot has `firmware/` and `cad/` folders.

| Robot | Job |
|---|---|
| [`cleaning-robot/`](cleaning-robot/) | Collects floating trash and offloads at dock points |
| [`outfall-patrol-boat/`](outfall-patrol-boat/) | Sensor boat that patrols banks, measures water quality and finds active sewage outfalls |
| [`thermal-drone/`](thermal-drone/) | Thermal camera drone that spots warm sewage plumes entering the river |

Dock points are on the map (layer `dock`).
